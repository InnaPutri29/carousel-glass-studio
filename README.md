# Carousel Glass Studio

Editor carousel Instagram bergaya liquid glass, langsung jalan di browser.

- Pilih jenis slide (sampul, polaroid, lensa di sambungan, grid, video, panorama, dll.), maksimal 20 slide.
- Isi foto/video: klik dua kali bingkai, tombol "Isi banyak foto/video sekaligus", atau seret file dari folder.
- Atur bentuk (kotak, kapsul, lengkung, bulat, blob, segi enam, belah ketupat, hati, bintang) dan gaya kaca (bening, embun, berwarna, glossy, pelangi, gelap).
- Tombol **Generate desain** dan **Acak warna & bentuk** untuk variasi otomatis.
- **Export semua slide** menghasilkan PNG 1080×1350 per slide (slide dengan video direkam jadi MP4/WebM), bisa diunduh sebagai ZIP.

Satu file `index.html`, tanpa build. Foto dan video tersimpan di browser pengguna (IndexedDB), tidak diunggah ke server mana pun.
